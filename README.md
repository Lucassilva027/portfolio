# Portfolio — Lucas Oliveira da Silva

Personal portfolio built with **Node.js**, **Express**, and **EJS** following the **MVC** architectural pattern. Supports bilingual content (🇺🇸 English / 🇧🇷 Portuguese). Pages are **pre-rendered to static HTML** for free, always-on hosting.

---

## ✨ Features

- **MVC Architecture** — clean separation between Models, Views, and Controllers
- **Bilingual (i18n)** — routes `/` (EN) and `/pt` (PT) with fully translated UI and content
- **Static site generation** — EJS templates rendered at build time into `dist/`
- **Static assets** — CSS, images, and JS served from the `public/` folder
- **Node.js native watch** — development mode with `node --watch` (no nodemon needed)

## 🚀 Getting Started

### Prerequisites

- Node.js **v18+** (v22 recommended)
- npm

### Installation

```bash
git clone https://github.com/Lucassilva027/portfolio.git
cd portfolio
npm install
```

### Local development (SSR)

```bash
npm run dev
```

Opens at **http://localhost:3000** (`/` EN, `/pt` PT).

### Static build + preview

```bash
npm run build      # writes dist/
npm run preview    # serves dist/ at http://localhost:4173
```

## ☁️ Deployment (Cloudflare Pages)

Host on **[Cloudflare Pages](https://pages.cloudflare.com/)** (always on, free SSL, CDN).

| Setting        | Value            |
|----------------|------------------|
| Build command  | `npm run build`  |
| Output dir     | `dist`           |
| Node version   | `22` (optional)  |

### Free URL (`*.pages.dev`)

Cloudflare gives a free address like `https://seu-projeto.pages.dev`.  
You choose the **project name** at create time — that becomes the subdomain.  
If the name is taken, Cloudflare adds a suffix. You can rename the project later in the dashboard (new `*.pages.dev` URL).

A short branded domain (`lucas.dev`, etc.) requires buying a domain; attaching it to Pages is free.
